# 公司与岗位招聘情报规范

在任何单岗位定向简历生成或更新前读取。目标不是写一份泛化公司介绍，而是用可追溯的公开证据判断：这家公司的这个业务线为什么招聘、岗位可能承担什么结果、企业真正购买哪些能力，以及这些判断如何改变简历定调。

## 1. 生成门槛与文件

- 每个仍可操作且准备进入深评或材料阶段的岗位，在同岗位资料目录维护一个稳定的 `公司与岗位情报.md`。
- 同岗位后续核验更新该文件，不创建“研究2”“最终研究版”等平行当前文件。
- 企业身份、岗位存在性或核心 JD 无法核验时，不生成定向简历；记录检索范围和唯一阻塞项。
- 企业直招岗位的汇报线、业绩或竞品单项未知不自动阻塞，必须如实标为未知。
- 已投递、HR 流程中、面试中、已结束、已失效或禁止回退的岗位不得因补做情报而回退或改写已投递材料；只有用户明确要求时才补研究记录。

## 2. 来源层级

按以下顺序查找，并记录页面标题、URL、页面发布日期或报告期、访问/核验日期、支持的结论和来源等级：

1. **一级来源**：企业官网职位页、企业招聘官网/公众号、企业认证 HR/TA、投资者关系、年报/财报、监管或交易所披露。
2. **二级来源**：企业官方产品页、官方新闻稿、领导层页面、官方社交账号和客户案例。
3. **三级来源**：政府/行业协会、可核验行业数据库、主流商业媒体和研究机构。
4. **线索来源**：招聘平台、猎头页、公开员工档案、评论和搜索摘要。只能用于定位或交叉验证，不能单独证明汇报线、经营业绩、团队规模或企业真实用人需求。

优先打开原始页面；搜索摘要只能证明摘要当时可见，不得替代可访问原文。付费墙、登录墙、反爬或页面缺失时记录限制，不绕过、不补写。

## 3. 固定研究结构

### A. 主体核验

- 标准公司名、品牌/业务线、产品或服务、城市。
- 职位发布主体：`企业直招 / 猎头线索 / 招聘机构 / 匿名客户 / 待核实`。
- 企业方职位核验：`同一企业职位已核验 / 仅发现相邻职位 / 未发现企业职位 / 企业未知 / 不适用`。
- 主链接优先企业官网或企业认证招聘页；猎头和平台链接进入备用来源。

### B. 当前招聘版图

扫描企业官网及固定招聘来源中当前可追溯的同业务线、品牌/市场相邻职能岗位，优先覆盖最近 90 天；只有可信日期明确超过 90 天才按旧岗位排除。至少归纳：

- 公开岗位数量和检索范围；没有结果时写 `在已列范围内未找到`，不得写“公司没有招聘”。
- 城市、职能、职级、业务线、核心技能、语言、团队管理和薪资口径。
- 同名或相近职位的重复发布、跨城市发布、职级梯度和能力组合。
- 哪些要求只出现在单条 JD，哪些在公司多个岗位中重复出现。

“当前招聘版图”是公开样本，不声称覆盖内部招聘、未公开岗位或全网全部职位。

### C. 业务与经营表现

- 业务线定位、产品组合、目标用户、渠道或商业模式。
- 最近一个可核验报告期的收入、增长、利润、销量、门店、用户或市场动作；只选择与目标业务线直接相关的指标。
- 重大产品发布、渠道扩张、组织调整、并购、降本或战略变化。
- 私营企业无公开财务时写未知，不用融资额、媒体估值或公司自述替代经营业绩。

### D. 组织与汇报架构

逐项标记：

- `已确认`：JD、企业组织图、领导层页面或官方材料直接写明。
- `高置信推断`：至少两个相互独立且时间接近的来源支持。
- `低置信线索`：只有一个间接来源或相邻岗位结构。
- `未知`：没有足够证据。

输出可能的直接汇报对象、上一级组织、下属/带教要求、关键跨部门协作方和岗位在品牌/市场组织中的位置。推断不得进入简历正文，也不得写成确定事实。

### E. 竞品与市场信号

选择 2–4 个直接竞品，说明选择依据，并比较与岗位相关的产品、渠道、市场动作、公开业绩或招聘信号。行业大盘不能替代公司或竞品事实；竞品数据报告期不同必须显著标记。

### F. 岗位 scorecard

把公司情报和 JD 合成为：

- 最可能要解决的 3–5 个业务问题。
- 预期业务结果和可观察交付。
- 必须入职前具备的能力、可入职后学习的能力、不可包装的硬门槛。
- 关键协作关系、决策权限和执行复杂度。
- 每条判断的证据来源和置信度。

不得把公司增长、招聘数量、媒体报道或竞品动作直接倒推出该岗位的 KPI；只能形成带置信度的岗位假设。

### G. 候选人证据映射

把scorecard与完整个人能力库逐项对照，性质/事实状态按 `decision-rubric.md` 和 `capability-library.md`：

- 可高可见呈现的 A 级证据。
- 需要真实转译的 B 级证据。
- C级：可说明的当前认知、方法与真实个人实践；有依据时积极表达，不因没有同行业职位而降为兴趣。
- D级：区分未知、冲突和确实缺口；未知不等于不会，短期补不齐项从正式简历省略。
- 明确哪些经历前置、后移、压缩或不写，并说明是由哪条公司/JD 信号触发。

### H. 结论与来源清单

输出研究结论、未知项、一个会改变结论的关键问题、核验日期和完整来源表。正文中的每个公司事实、数字和汇报判断必须能回到来源表。

## 4. 猎头线索分支

猎头、招聘机构和匿名客户职位只作为企业线索，不能直接进入 Top 5、深评或材料生成：

1. 从公司线索、行业、产品、城市、薪资、职责片段和职位编号反查真实用人企业。
2. 查找企业官网、企业认证招聘渠道和同一或高度对应职位。
3. **找到同一企业方职位**：保留同一岗位编号；把企业方链接设为主链接，猎头页设为备用链接；更新标准公司名和 JD 差异，再进入完整情报门。
4. **只识别出企业但没有同一企业方职位**：状态写 `已结束`，结束原因为 `未找到同一企业方职位`；不生成定向简历。
5. **企业身份无法核验**：状态写 `已结束`，结束原因为 `猎头线索无法核验真实用人企业`；不生成定向简历。
6. 已投递、HR 流程中或面试中的猎头岗位不自动结束、不删除、不回退；只补充核验结果和风险。

对没有投递历史且因第 4 或第 5 项结束的岗位，按共享契约的“系统核验猎头终止清理”保留灰色台账事实行，安全删除该岗位资料包和单岗位资产记录。

## 5. Word 前置摘要

完整情报保存在 Markdown 文件。当前 Word 审阅稿在完整 JD 之前放一页以内的摘要：

1. 主体和业务线。
2. 当前招聘版图的 3–5 个信号。
3. 业务/业绩与竞品的关键事实。
4. 汇报架构与岗位位置，保留置信度。
5. 岗位 scorecard 和简历定调重点。
6. 来源编号、核验日期和未知项。

该摘要属于审阅区，不进入分页后的简历正文。公司推断、匹配结论、风险辩护和来源标注均不得出现在简历正文。

## 6. 停止条件

完成以下动作即可停止，不进行无边界搜索：

- 核验职位主链接和招聘主体。
- 检查企业官网/招聘页及固定招聘来源的同业务线岗位。
- 检查最近可得的官方经营材料；无公开材料时记录未知。
- 检查 2–4 个直接竞品的同口径信号。
- 对汇报架构至少完成官方材料和相邻岗位结构两类尝试。
- 所有结论已有来源等级、日期和置信度；无法确认的项目已明确标为未知。
