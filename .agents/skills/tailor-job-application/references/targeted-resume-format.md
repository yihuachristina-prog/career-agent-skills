# 定向简历格式母版

本规范提供品牌营销简历的默认视觉参数；以当前用户确认模板为准。它只记录不含个人敏感信息的格式参数，不复制母版正文、联系方式或照片。所有新生成和后续更新的定向简历都必须遵守；若用户当次明确给出更高优先级的格式要求，以当次要求为准并记录例外。

## 1. 适用边界

- 审阅稿由“公司与岗位情报/JD 审阅区”和“简历正文”组成。两区必须用下一页分节隔开，不能只靠普通空行或在正文内继续堆叠分页符。
- 审阅区保留其清晰、可核验的原布局，只统一字体为微软雅黑。
- 简历正文使用本规范的页面、标题、正文、项目和间距参数。
- 已存在的照片、英文版结构、单行/双行联系方式等可见局部例外可以保留，但底层可见文字字体仍须统一为微软雅黑。
- 不得为了套版改写事实、删减证据或改变栏目语义。

## 2. 字体硬门槛

- 所有可见文字统一使用 `Microsoft YaHei`（微软雅黑），包括中文、英文、数字、符号、超链接、页眉和页脚。
- 每个可见 run 的 `ascii`、`hAnsi`、`eastAsia`、`cs` 字体属性均显式写为 `Microsoft YaHei`，不能依赖主题字体或系统回退。
- 生成前检查本机字体。Windows 可接受的字体文件包括 `msyh.ttc`、`msyhbd.ttc`、`msyhl.ttc`。若均不存在，停止生成和交付；只有用户明确授权时才下载或安装。
- 不因文档中未使用的旧样式仍引用宋体、Arial 或其他字体而判失败；审计对象是所有可见文字和实际使用的样式。

## 3. 简历正文页面参数

| 下边距 | 0.4701 英寸（约 11.94 mm） |
| 左边距 | 0.6201 英寸（约 15.75 mm） |
| 右边距 | 0.6201 英寸（约 15.75 mm） |
| 页眉距离 | 0.2799 英寸（约 7.11 mm） |
| 页脚距离 | 0.2799 英寸（约 7.11 mm） |

正文采用自然分页。除审阅区与正文之间的下一页分节外，不在简历正文中插入显式分页符；优先通过信息密度、重复内容和段落控制修复分页。

## 5. 结构与可见例外

- 推荐栏目顺序：个人简介、核心能力、工作经历、代表/重点项目、教育背景；岗位需要时可增减栏目，但标题层级不变。
- 姓名区可以继续使用现有表格、照片和列宽，不强制所有旧稿增加照片。确认母版中的参考头像尺寸约为 1.1424 × 1.4986 英寸，只有现有文档已含照片或用户明确要求时才沿用。
- 母版参考页眉表格为 1 行 2 列，宽度约 7299/2795 twips，单元格垂直居中；这是可见布局参考，不是所有岗位的强制结构。
- 英文版可以保留英文栏目名与内容结构，但字号、颜色、段距、页面和微软雅黑规则不变。

## 6. 生成与验收

每次生成或更新后必须运行：

```powershell
python scripts/audit_resume_delivery.py <resume.docx> --after-page-break --check-format --require-font-installed
```

干净投递稿不含审阅区时去掉 `--after-page-break`。自动审计通过后仍须渲染逐页检查：缺字、重叠、截断、孤行、异常空白、项目符号错位、标题与正文脱节。内容/结构验收与视觉验收分开记录；未完成渲染不得声称视觉验收通过。
