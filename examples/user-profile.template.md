# 当前用户求职配置模板

- 用户 ID：待填写（非联系方式）
- 资料工作区和唯一主库：待指定
- 目标城市及顺序：待确认
- 岗位方向、职级、行业边界：待确认
- 当前月固定薪资 `current_monthly_base_rmb`：待确认
- 当前年包 `current_annual_rmb`：待确认
- offer 年包下限 `offer_floor_rmb`：待确认
- 招聘区间上限门槛 `listing_max_floor_rmb`：待确认
- 招聘区间下限偏好 `listing_min_preference_rmb`：待确认
- 语言、管理与职责边界：待确认
- 原始简历、用户确认模板和能力证据：待提供路径
- 姓名检查标记、项目名称检查标记：从真实简历提取
- 固定职业时间线及锁定正文：仅填当前用户已确认的真实内容
- 清理授权：未授权；如已有明确授权，记录来源、范围、例外和时间
- 对外投递与沟通：仅依据当前用户明确指令

这是输入模板；未知字段保留待确认，不写入正式简历作为占位符。
